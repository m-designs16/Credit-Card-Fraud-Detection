# 💳 Credit Card Fraud Detection

A Machine Learning based web application that detects whether a credit card transaction is **Fraudulent** or **Legitimate**.

The project uses **Logistic Regression** for classification and **Streamlit** to provide an interactive web interface.

## 🚀 Features

- Detects fraudulent and legitimate transactions
- Interactive Streamlit web interface
- Displays the actual transaction value
- Shows transaction details
- Uses a trained Logistic Regression model
- Handles imbalanced transaction data using sampling
- Easy to run locally and deploy online

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Streamlit
- Jupyter Notebook
- Git & GitHub
